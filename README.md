# BD: Sprint Plan

План главы 1 Bullet's Deal, только для просмотра. Редактирует Дима на странице в claude.ai, сюда выкладывается свежая выгрузка.

Открыть: `https://<аккаунт>.github.io/<название-репозитория>/`

## Первая настройка (один раз, через GitHub Desktop)

1. В GitHub Desktop: **Commit to main** (файлы `index.html`, `.nojekyll`, `README.md`).
2. **Publish repository**.
   - Галочку **Keep this code private** сними, если у вас бесплатный GitHub: Pages для приватных репозиториев работает только на платных планах.
   - Публичный сайт откроет любой, у кого есть ссылка.
3. На github.com в репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сверху в Settings → Pages появится ссылка на сайт. Её кидаешь команде.

Если название репозитория с пробелом или двоеточием, GitHub заменит их на дефисы, например `BD-Sprint-Plan`.

## Как обновлять

1. Открой страницу плана в claude.ai и нажми **«Скопировать для сайта»** (кнопка рядом с «+ Майлстоун»).
2. Дважды кликни **update-site.command** в этой папке. Скрипт:
   - возьмёт план из буфера обмена;
   - соберёт `index.html` из `site-template.html`;
   - сделает коммит «План от ДД.ММ.ГГГГ» и запушит его.
3. Через 1–2 минуты сайт обновится. Ссылка не меняется.

Если macOS при первом запуске пишет, что файл от неизвестного разработчика: правый клик → **Открыть** → **Открыть**. Это нужно один раз.

Если в терминале нет git, скрипт только соберёт `index.html`, а коммит и пуш делаются в GitHub Desktop: **Commit to main → Push origin**.

`site-template.html` не трогай: это шаблон страницы. Когда Claude меняет вид сайта, он обновляет этот файл.
